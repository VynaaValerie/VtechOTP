Authentication

All API requests must include your developer API Bearer token in the Authorization HTTP header:

HTTP Header 
Authorization: Bearer vtk_your_api_token_here
Content-Type: application/json

Base URL

Direct all REST API requests to either the official production endpoint or web portal gateway:

Production Server: https://app.otp.vtech.biz.id/api/v1
Web Gateway: https://vtechotp.web.id/api/v1

Fetches your current coin balance, number of currently active orders, and maximum concurrent order slots.

Real-Time Webhooks

Instead of polling /orders/{id} repeatedly, register a webhook URL to receive instant push events when SMS arrives.

Webhook Events Dispatched:
• order.otp_received — Incoming SMS received
• order.completed — Order marked finished
• order.canceled — Canceled with refund
• order.expired — Timeout reached with 100% auto-refund

HMAC-SHA256 Signature Verification

Every webhook POST includes an X-VTech-Signature header. Verify it using your webhook secret:

const crypto = require('crypto');

function verifyWebhook(rawBody, signatureHeader, secret) {
  const hash = crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(hash), Buffer.from(signatureHeader));
}
import hmac
import hashlib

def verify_webhook(raw_body_bytes, signature_header, secret_key):
    expected = hmac.new(secret_key.encode('utf-8'), raw_body_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)

Error Codes Reference

Standardized JSON error responses and recommended developer actions:

Error Code HTTP Status Description & Resolution
UNAUTHORIZED401Missing Authorization header in request
INVALID_TOKEN401Bearer token is invalid or expired
INSUFFICIENT_BALANCE409Coin balance too low to create order. Top up required.
MAX_ACTIVE_ORDERS_EXCEEDED429Maximum concurrent active orders limit reached (default 5). Complete or cancel existing orders.
NO_OFFER_AVAILABLE422Stock for requested country & platform currently depleted. Try another operator or country.
ORDER_NOT_FOUND404Specified order ID does not exist or belongs to another user.
