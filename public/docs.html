Dokumentasi VTechOTP Developer API v1

Akses terprogram untuk sewa nomor virtual, otomatisasi penerimaan SMS/OTP, pengecekan saldo, dan notifikasi real-time webhook berbasis mata uang Rupiah (1 Coin = 1 IDR).

Arsitektur RESTful Standar: Developer API ini dirancang mengikuti format standar RESTful sehingga mudah dihubungkan dengan bot Telegram, skrip otomatisasi, bot Discord, maupun sistem reseller Anda.

Autentikasi

Setiap request ke API harus menyertakan API Token Anda pada HTTP Header Authorization dengan format Bearer token:

HTTP Header 
Authorization: Bearer vtk_your_api_token_here

Anda dapat membuat atau memperbarui API Token kapan saja melalui menu Profil > Developer API & Webhook di aplikasi VTechOTP.

Base URL

Semua request API diarahkan ke endpoint resmi berikut:

https://app.otp.vtech.biz.id/api/v1

Daftar Saluran Pembayaran & Cek Status Live (ON/OFF)

GET /deposits/channels (alias: /deposit/channels)

Mendapatkan daftar seluruh metode/saluran pembayaran yang didukung payment gateway secara real-time. Endpoint ini menampilkan status aktif/gangguan (status: "ON" atau "OFF"), batas minimum/maksimum nominal, dan biaya fee pada masing-masing saluran sehingga bot atau aplikasi Anda dapat memvalidasi saluran mana yang sedang online sebelum membuat tagihan invoice.

Daftar Kode Saluran (service_id) Populer:
• QRIS Realtime: 11 (Min. Rp 100 / Rp 1.000, Max. Rp 10.000.000) — Rekomendasi Utama
• Virtual Account (VA): BCA (1), BRI (2), BNI (4), Mandiri (5), CIMB (3), Permata (7), Danamon (8), BSI (9), Neo (10), OCBC (21), Muamalat (22) (Min. Rp 10.000)
• E-Wallet: OVO (12 - butuh parameter phone)
• Gerai Retail: Alfamart/Alfamidi (18), Indomaret/Ceriamart (19) (Min. Rp 10.000)

Buat Tagihan Deposit (QRIS, VA, E-Wallet, Retail)

POST /deposits/create (alias: /deposit/create, /deposits)

Membuat tagihan invoice deposit saldo koin baru via payment gateway. Mendukung pembuatan tagihan otomatis untuk QRIS Realtime (mengembalikan gambar PNG, Base64, dan raw payload), Virtual Account (mengembalikan nomor VA), E-Wallet, dan Gerai Retail (Alfamart/Indomaret).

Parameter BodyTipeWajib?Deskripsi
amountintegerWajibNominal deposit dalam Rupiah (min. Rp 1.000 untuk QRIS, min. Rp 10.000 untuk VA/Retail)
service_idstring / integerOpsionalKode saluran pembayaran (contoh: "11" = QRIS, "1" = BCA VA, "2" = BRI VA, "4" = BNI VA, "18" = Alfamart, dll. Default: "11")
methodstringOpsionalMetode pembayaran jika tidak mengirim service_id: "QRIS", "VA", "E-Wallet", "Retail"
phonestringOpsionalNomor HP pelanggan (wajib jika memilih metode OVO / service_id "12")

Verifikasi HMAC-SHA256 Signature

Setiap panggilan webhook menyertakan header X-Webhook-Signature untuk memastikan request benar-benar berasal dari server resmi VTechOTP.

const crypto = require('crypto');

app.post('/my-webhook-handler', (req, res) => {
  const signature = req.headers['x-webhook-signature'];
  const webhookSecret = 'sec_your_webhook_secret_here';

  const expectedSig = 'sha256=' + crypto
    .createHmac('sha256', webhookSecret)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (signature !== expectedSig) {
    return res.status(401).send('Invalid signature');
  }

  const { event, data } = req.body;
  if (event === 'order.otp_received') {
    console.log(`OTP Masuk: ${data.otp_code} untuk ${data.phone_number}`);
  } else if (event === 'deposit.credited') {
    console.log(`Deposit Berhasil: Rp ${data.net_coins} telah masuk.`);
  }

  res.status(200).send('OK');
});
import hmac, hashlib, json
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/my-webhook-handler', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('X-Webhook-Signature', '')
    webhook_secret = b'sec_your_webhook_secret_here'
    
    expected_sig = 'sha256=' + hmac.new(webhook_secret, request.data, hashlib.sha256).hexdigest()
    
    if not hmac.compare_digest(signature, expected_sig):
        return jsonify({'error': 'Invalid signature'}), 401
        
    payload = request.get_json()
    print(f"Event: {payload['event']}, Data: {payload.get('data')}")
    return jsonify({'status': 'ok'}), 200
